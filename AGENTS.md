# Permanent Project Rules & Guidelines

## FixHome Application Logo
- **Logo File**: `/public/fixhome_logo.jpg` and `src/assets/logoData.ts` (exporting `export const FIXHOME_LOGO = "data:image/jpeg;base64,..."`) contain the official, exact user-approved FixHome logo (navy background, white house outline, 4 colored grid icons for electricity, plumbing, painting, hammer, and 'FIXHOME - YOUR HOME, OUR CARE' tagline).
- **Rule**: Do NOT replace, modify, regenerate, or alter this logo file or image in any way. Keep the logo image exactly as provided. It is embedded directly as an inline base64 string so it displays instantly with zero network delay even on low internet or offline connections.
- **Consent Rule**: Always ask for explicit user consent before modifying code in major core files.
